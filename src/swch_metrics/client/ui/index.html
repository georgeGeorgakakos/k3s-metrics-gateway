Gateways · k3s clusters

Every k3s cluster runs one k3s Metrics Gateway. This sidecar polls all enabled gateways with every collector and labels each sample with its cluster.

Automatic registration

A gateway deployed on a new k3s host announces itself here and is polled straight away, with no manual step on the EMS host. It repeats the announcement every 5 minutes as a heartbeat.

Onboard a new k3s host

On the new host (k3s with Traefik on port 80):

Persistence

        
Saved configuration is written to /data/client.yaml and, through the gateway, to the
          swch-metrics-client-config-saved ConfigMap, so it survives pod restarts and is never overwritten when k3s re-applies the deployment manifest.
